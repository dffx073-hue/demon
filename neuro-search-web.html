Нейропоиск по интернету

Ищет по-настоящему в интернете (через открытый API Wikipedia — без ключа, без сервера) и подсказывает варианты запроса на лету. Результаты переранжирует маленькая нейросеть, которая учится на ваших кликах.

сеть готова
Источник данных — ru.wikipedia.org/w/api.php, открытый и бесплатный, работает прямо из браузера без ключа. Если нужен поиск как в Google/Bing по всему вебу — это возможно, но только с API-ключом (Google Programmable Search, Bing Search API или SerpAPI), потому что сами поисковики не разрешают браузеру стучаться к ним напрямую. Функция fetchResults() ниже — единственное место, которое нужно поменять на такой API.
